# Реєстр юридично чутливих тверджень

Місця, де сайт робить твердження, що потребують уваги адвоката та власника.
Формулювання навмисно обережні — не змінюйте їх на «сильніші» без юридичної
перевірки.

## Твердження про результат (свідомо обмежені)

| Місце | Твердження | Чому чутливе |
|---|---|---|
| TrustBlock, /zatrymka-abo-vidmova, FAQ «no-guarantee» | «Ми не обіцяємо результат без аналізу документів…» | Ключове анти-маніпулятивне формулювання; не замінювати на обіцянки |
| StepsBlock | «ми не обіцяємо фіксованих строків отримання виплати» | Заборона обіцянок строків державних виплат |
| HelpGrid, PaymentsList, /inshi-vyplaty | «перелік не є гарантією отримання» | Захист від враження гарантованої виплати |
| Reviews | «Результат в іншій справі може відрізнятися» | Обов'язковий дисклеймер до відгуків |

## Статус спеціаліста

| Місце | Твердження | Умова |
|---|---|---|
| src/config/site.ts → team[].role | «Юрист» / «Адвокат» | «Адвокат» лише за чинного свідоцтва |
| TrustBlock | «Статус адвоката можна перевірити» | показується лише коли `hasAttorney === true` |
| confidentialityTerm | «конфіденційність звернення» vs «адвокатська таємниця» | автоматично залежить від `hasAttorney` |

## Умови та ціни

| Місце | Твердження | Умова |
|---|---|---|
| site.initialCallTerms | умови первинного дзвінка | НЕ заявляти «безкоштовну консультацію» без підтвердження власника |
| site.callbackTimePromise | «у межах графіка роботи» | НЕ обіцяти конкретний час дзвінка без гарантії команди |
| pricing.* | ціни | НЕ вигадувати; поки порожні — показується загальний текст |

## Нормативна інформація

| Місце | Стан |
|---|---|
| src/content/payments.ts | суми/строки/коло отримувачів приховані за позначкою `[ПОТРІБНА ПЕРЕВІРКА АДВОКАТОМ ПЕРЕД ПУБЛІКАЦІЄЮ]` |
| src/content/articles.ts | всі статті `reviewed: false` → банер «очікує перевірки» |
| OfficialSources | лише офіційні державні ресурси; конкретні акти додає адвокат |

## Дисклеймери (не видаляти)

- Footer + інформаційні сторінки: «Матеріали сайту мають загальний інформаційний характер…»
- Footer + /umovy-korystuvannia: «Цей сайт не є сайтом Міністерства оборони України, ТЦК та СП…»
- LegalNotice на кожній інформаційній сторінці
- SensitiveDataNotice у формі: заборона надсилати паспорт/РНОКПП/реквізити
- «Інформацію оновлено: {дата}» (LegalMeta) на інформаційних сторінках

## Заборонені прийоми (перевірено — відсутні)

Гарантії виплат, «100% результат», суми на кшталт «отримаємо 15 мільйонів»,
«найкращі адвокати», таймери, лічильники заявок, фальшиві відгуки, вигадана
статистика, маніпулятивні фото. Не додавати їх і надалі.
