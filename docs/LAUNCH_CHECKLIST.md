- [ ] Сайт відкривається лише по HTTPS

- [ ] Секрети не витікають на клієнт (пошук `TURNSTILE_SECRET` у вихідному коді сторінки)
- [ ] Rate limiting перевірено (6+ швидких сабмітів → 429)
- [ ] У логах немає персональних даних
