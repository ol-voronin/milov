# Telegram-бот: сповіщення про нові заявки

Коли людина залишає заявку на сайті, вам одразу приходить повідомлення
в Telegram — з іменем, телефоном, темою звернення і сторінкою, з якої
надійшла заявка. У повідомленні є кнопка «Подзвонити».

Налаштування займає ~5 хвилин.

---

## Крок 1. Створити бота

1. Відкрийте Telegram і знайдіть **@BotFather** (офіційний бот з синьою галочкою).
2. Надішліть команду `/newbot`.
3. Введіть назву бота, наприклад: `Заявки — Назва практики`.
4. Введіть username бота — має закінчуватись на `bot`, наприклад: `nazva_praktyky_leads_bot`.
5. BotFather надішле **токен** — довгий рядок виду:

   ```
   1234567890:AAEhBOweik6ad9r_ScGqRjnKfP0mTgXsL2Y
   ```

⚠️ Токен = пароль від бота. Нікому не показуйте, не комітьте в git.

---

## Крок 2. Дізнатися свій chat id

Бот не може написати першим — спершу ви маєте написати йому.

1. Знайдіть свого бота за username і натисніть **Start** (або надішліть будь-яке слово).
2. Відкрийте у браузері (підставте свій токен):

   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```

3. У відповіді знайдіть `"chat":{"id":123456789`. Це число — ваш **chat id**.

Альтернатива: напишіть боту **@userinfobot** — він одразу покаже ваш id.

---

## Крок 3. (Опційно) Сповіщення в групу

Якщо заявки має бачити кілька людей:

1. Створіть групу в Telegram і додайте туди свого бота.
2. Надішліть у групу будь-яке повідомлення.
3. Відкрийте `getUpdates` (див. крок 2) — id групи буде **від'ємним** числом,
   наприклад `-1001234567890`.
4. Використайте це число як `TELEGRAM_CHAT_ID`.

Для груп-супергруп також вимкніть у BotFather **Group Privacy**
(`/mybots` → ваш бот → Bot Settings → Group Privacy → Turn off),
інакше бот може не бачити повідомлень.

---

## Крок 4. Додати змінні на сайт

**Локально** — у файл `.env.local`:

```bash
TELEGRAM_BOT_TOKEN=1234567890:AAEhBOweik6ad9r_ScGqRjnKfP0mTgXsL2Y
TELEGRAM_CHAT_ID=123456789
```

**На Vercel** — Settings → Environment Variables → додайте обидві змінні
(для Production, Preview і Development) → Redeploy.

⚠️ Змінні **без** префікса `NEXT_PUBLIC_` — токен залишається на сервері
й ніколи не потрапляє в браузер.

---

## Крок 5. Перевірити

1. Відкрийте сайт, натисніть «Замовити дзвінок», заповніть форму.
2. Протягом кількох секунд бот має надіслати повідомлення:

```
🔔 Нова заявка з сайту

👤 Ім'я: Олена
📞 Телефон: +380 67 123 45 67
📌 Тема: Затримка виплати

🌐 Сторінка: /zatrymka-abo-vidmova
⏰ Отримано: 28.07.2026 14:32 (Київ)

[ 📞 Подзвонити ]
```

Якщо повідомлення не прийшло — перевірте у логах Vercel рядок
`[telegram] send failed` із кодом помилки:

| Код | Причина |
|---|---|
| 401 | Невірний токен |
| 400 (`chat not found`) | Невірний chat id, або ви не натиснули Start у боті |
| 403 | Бота заблоковано або видалено з групи |

## Як це працює технічно

- `src/lib/telegram.ts` — формування та надсилання повідомлення.
- `src/app/api/lead/route.ts` — викликає `notifyTelegram()` після успішної
  валідації заявки.
- Помилка Telegram **не ламає форму**: людина в будь-якому разі побачить
  сторінку подяки. Якщо Telegram отримав заявку, а webhook/CRM — ні,
  користувачу теж не показується помилка (заявка не втрачена).
- Таймаут запиту — 5 секунд, щоб форма не «висіла».
- У логи не пишеться вміст заявки — лише код помилки.

## Приватність

Telegram отримує ті самі мінімальні дані, що й ваша CRM: ім'я, телефон,
тему і (якщо людина заповнила) короткий опис. Це варто відобразити в
розділі «Кому можуть передаватися дані» політики конфіденційності —
позначено в `docs/LEGAL_REVIEW.md`.
