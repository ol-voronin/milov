# SEO та реклама zastupa.com.ua

## 1. Google Search Console — підключення

### Що це дає

Google Search Console показує, за якими запитами сайт з'являється в пошуку,
скільки людей бачать його і скільки натискають. Без нього ви літаєте наосліп —
не знаєте, чи взагалі Google бачить сайт.

### Крок 1: додати ресурс

1. Відкрийте [search.google.com/search-console](https://search.google.com/search-console)
2. Увійдіть з акаунта, який буде власником (краще — окремий робочий Gmail)
3. Натисніть **Додати ресурс** → виберіть **Домен** → введіть `zastupa.com.ua`

### Крок 2: верифікація через DNS TXT

Google покаже TXT-запис виду:
```
google-site-verification=XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

Додайте його в DNS через HOSTiQ:

1. [hostiq.ua](https://hostiq.ua) → Увійти → Мої домени → zastupa.com.ua → **Керувати DNS**
2. Додайте запис:
   - Тип: **TXT**
   - Ім'я: `@` (або порожнє — залежить від інтерфейсу)
   - Значення: скопійований рядок `google-site-verification=...`
   - TTL: 3600

⚠️ НЕ додавайте через cPanel Zone Editor — він не авторитетний, зміни не подіють.
DNS-зона живе в HOSTiQ (Cloudflare партнерський акаунт), а не в cPanel.

3. Зачекайте 5–30 хвилин і натисніть **Підтвердити** в Search Console.

### Крок 3: подати sitemap

Після верифікації:
1. Зайдіть у Search Console → Файли Sitemap
2. Введіть: `https://zastupa.com.ua/sitemap.xml`
3. Натисніть **Надіслати**

Sitemap уже генерується автоматично і містить усі 14 статичних сторінок + статті.

### Крок 4: запросити індексацію

У розділі **Перевірка URL** вставте головну сторінку:
```
https://zastupa.com.ua/
```
Натисніть **Запросити індексацію**. Повторіть для 3–4 найважливіших сторінок:
- `https://zastupa.com.ua/vyplaty-u-razi-zagybeli`
- `https://zastupa.com.ua/zatrymka-abo-vidmova`
- `https://zastupa.com.ua/znykli-bezvisty-ta-poloneni`
- `https://zastupa.com.ua/faq`

Google почне обходити решту сам через sitemap.

## 2. Google Ads — готові тексти оголошень

### Обмеження, які враховано

- Google забороняє гарантувати результат юридичних послуг
- Google відносить «особисті нещастя» до чутливих категорій — обмежений таргетинг
- Стаття 13 Правил адвокатської етики забороняє заяви про вірогідність успіху
- ТЗ проєкту забороняє «гарантуємо виплату», «100% результат»

### Кампанія 1: Виплати загиблим

**Заголовки (до 30 символів кожен):**

1. `Виплати родині загиблого`
2. `Допомога з документами`
3. `Перевіримо право на виплати`
4. `Юрист по всій Україні`
5. `Консультація телефоном`
6. `Затримують виплату?`
7. `Відмовили у виплаті?`
8. `Заступа — права родин`

**Описи (до 90 символів кожен):**

1. `Перевіримо документи, пояснимо порядок дій. Працюємо по всій Україні, онлайн і телефоном.`
2. `Допомагаємо оформити належні виплати родинам загиблих військовослужбовців. Без прихованих платежів.`
3. `Затримують або відмовили? Оскаржимо бездіяльність. Юридичний супровід від заяви до результату.`
4. `Які виплати належать вашій родині? Проаналізуємо ситуацію та пояснимо, з чого почати.`

**Ключові слова:**

```
виплати загиблому військовослужбовцю
виплати родині загиблого військового
одноразова грошова допомога загиблий
виплати сім'ї загиблого
допомога родинам загиблих військових
юрист виплати загиблий військовий
оформити виплати загиблого
відмова у виплаті загиблому
затримка виплати загиблому
оскаржити відмову у виплаті
```

### Кампанія 2: Зниклі безвісти та полонені

### Рекомендації по налаштуванню

**Геотаргетинг:** уся Україна. Сайт працює дистанційно — немає сенсу обмежувати містом.

**Бюджет:** 3000–5000 грн/міс на старті. Юридична тематика — 5–15 грн за клік.

**Розклад показів:** Пн–Пт 8:00–20:00. Більшість дзвінків — у робочий час.

**Стратегія ставок:** почніть з «Максимум кліків» із обмеженням ставки 20 грн.
Через 2–3 тижні, коли буде 30+ конверсій, переходьте на «Максимум конверсій».

**Конверсія:** відстежуйте подію форми — відповідь API `/api/lead` з `{ ok: true }`.
Код конверсії Google Ads додається в `src/components/Analytics.tsx`.

⚠️ **Не додавайте Google Ads conversion pixel до CSP.** Спершу додайте домен
`https://www.googleadservices.com` і `https://www.google.com` у `script-src` і
`connect-src` у `next.config.mjs` — інакше CSP заблокує скрипт і конверсії
не будуть рахуватися.

## 3. Що ще зробити для органічного трафіку

### Вже зроблено (цей коміт)

- Structured data: LegalService з ContactPoint і OfferCatalog, WebSite з SearchAction, FAQPage, BreadcrumbList
- Sitemap з диференційованими пріоритетами (виплати 0.9, правова інформація 0.3)
- OG-теги для соцмереж на всіх ключових сторінках
- robots.txt: дозволяє все крім /api/ і /dyakuyemo

### Далі (органіка, без бюджету)

1. **Google Business Profile** — зареєструйте «Заступа» як юридичну практику
   в Google Maps (навіть без фізичного офісу — є формат «сервіс на виїзді»).
   Це дає картку з телефоном прямо в пошуковій видачі.

2. **Відгуки** — попросіть 3–5 перших клієнтів залишити відгук у Google.
   E-E-A-T для юридичних сайтів значною мірою будується на відгуках.

3. **Зворотні посилання** — розмістіть інформацію про практику в каталогах:
   - [ЮрЛіга](https://jurliga.ligazakon.net)
   - Каталог адвокатів ЄРАУ (якщо є адвокати)
   - Telegram-канали для родин військових (органічно, не спам)

4. **Контент-маркетинг** — розділ «Корисна інформація» вже містить 5 статей.
   Додавайте 1–2 статті на місяць за реальними запитаннями клієнтів.
