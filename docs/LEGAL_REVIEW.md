# Матеріали для перевірки адвокатом перед публікацією

Позначка в коді та контенті: `[ПОТРІБНА ПЕРЕВІРКА АДВОКАТОМ ПЕРЕД ПУБЛІКАЦІЄЮ]`
(константа `NEEDS_LAWYER_REVIEW` у `src/content/payments.ts`).

Поки позначка стоїть у полі виплати — значення поля **не показується
відвідувачам**. Після перевірки: замініть текст на перевірений, заповніть
`lastVerifiedAt` (дата) і `verifiedBy` (хто перевірив).

## 1. Виплати — src/content/payments.ts

Для кожного запису перевірити та заповнити з посиланням на чинну редакцію
нормативного акта:

- [ ] Одноразова грошова допомога: розмір, порядок виплати, коло отримувачів, вплив особистого розпорядження, строки звернення
- [ ] Невиплачене грошове забезпечення: хто отримує, порядок
- [ ] Додаткова винагорода: підстави, розмір, порядок
- [ ] Компенсація за невикористані відпустки: порядок
- [ ] Пенсія у зв'язку з втратою годувальника: умови, розмір, порядок
- [ ] Допомога на поховання: розмір, порядок
- [ ] Статус члена сім'ї загиблого Захисника/Захисниці: умови, порядок оформлення
- [ ] Додати конкретні посилання на акти (зараз — лише головні сторінки офіційних ресурсів)

## 2. Статті — src/content/articles.ts (усі reviewed: false)

- [ ] «Перші кроки після загибелі військовослужбовця» (+ PDF-версія у public/downloads/)
- [ ] «Виплату затримують: як діяти» (строки розгляду звернень)
- [ ] «Отримали відмову у виплаті: що далі» (строки оскарження)
- [ ] «Проживання без реєстрації шлюбу» (порядок встановлення факту)
- [ ] «Родинам зниклих безвісти» (актуальні органи та порядок)

Після перевірки поставте `reviewed: true` і `reviewedBy` — на сторінці
з'явиться позначка «Перевірено адвокатом» (лише якщо в команді є адвокат).
