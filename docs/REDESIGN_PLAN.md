# План перебудови: навігація, повітря, типографіка, шаблонність

Складено 1 серпня 2026. Усі цифри — заміри в Chromium на 1280×900, а не оцінки на око.

---

## Частина 1. Діагноз

### 1.1. Навігація нічого не обіцяє

Поточна шапка: `[Ситуації ▾] Послуги · Корисна інформація · Про нас · Контакти`

| Проблема | Чому це болить саме тут |
|---|---|
| «Ситуації» — абстракція | Жінка, у якої вчора загинув чоловік, не шукає очима «ситуації». Вона шукає «загинув», «виплати», «відмовили» |
| «Корисна інформація» ≠ нічого | Під цією назвою може бути що завгодно. Насправді там покрокові інструкції та чекліст PDF |
| «Послуги» і «Ситуації» перетинаються | Обидва ведуть до «що ми робимо», користувач не розуміє, який шлях його |
| Немає підказки, що за посиланням | У випадайці підписи є, у шапці й мобільному меню — ні |
| Мобільне меню — плоский список із 9 пунктів | Без групування, без ієрархії |
| Футер: колонка «Практика» | Змішує Послуги + Про команду + FAQ + Статті. Це чотири різні наміри |
| Сторінки — глухі кути | Внизу кожної один і той самий CTA. Немає «а що далі за темою» |

### 1.2. Повітря: заміряні розриви між секціями

```
Затримка / Зниклі        32px між усіма секціями
FAQ                       4px між елементами акордеона
Корисна інформація       16px між пошуком, фільтром і списком
Головна, Виплати,
Послуги, Про команду,
Контакти                  0px — секції стикуються впритул
```

32px між великими смисловими блоками — це відступ рівня «абзац», а не «розділ».
Око не бачить, де закінчився один блок і почався інший. На сторінці «Затримка»
два блоки «покроково» по 4 кроки читаються як один список із 8 кроків.

### 1.3. Типографіка

| Роль | Зараз | Проблема |
|---|---|---|
| h1 | 34px / 44 | Лише в 1,3 раза більший за h2 — ієрархії майже немає |
| h2 | 26px / 36 | |
| h3 | не використовується | Третій рівень просто відсутній |
| Основний текст | 16px / 24 (1,5) | Для довгих українських текстів інтерліньяж тісний |
| Допоміжний | **13px / 20** | 39 елементів на одній сторінці. Це замало навіть для здорових очей |
| Довжина рядка | до **1120px** | ≈150 символів. Комфортна межа — 65–75 |

Пара Source Serif 4 + Source Sans 3 технічно бездоганна, але це найпоширеніший
безкоштовний суперсімейний набір. Він і створює половину відчуття «дефолтного
шаблону».

### 1.4. Чому виглядає як шаблон

Скільки сторінок використовують один і той самий блок:

```
FinalCta «Не знаєте, з чого почати?»   13 з 13 сторінок
PageHero з фото                        12 з 13
WeHelpBlock «Чим допомагаємо ми»        4
CaseFlow «Шлях справи»                  3
```

Користувач, який відкрив три сторінки поспіль, тричі побачив однакове фото-полотно
згори, однакові скруглені картки в сітці 2×2 та однаковий синій CTA знизу. Ритм
сторінок ідентичний. Саме це читається як «генерував автомат», а не колірна гама.

Додатково: **hero-фото хотлінкаються з images.unsplash.com**. Коли CDN недоступний,
на місці банера показується alt-текст. Це видно на всіх замірах.

### 1.5. Другорядні сторінки

| Сторінка | Висота | Слів | Що не так |
|---|---|---|---|
| Контакти | 1533px | 207 | Hero з'їдає 428px (28% сторінки) заради одного рядка |
| FAQ | 2116px | 255 | 12 позицій акордеона по 61px із розривом 4px — суцільна смуга |
| Корисна інформація | 2949px | 429 | Два CTA поспіль внизу: «Не знайшли відповідь?» і «Не знаєте, з чого почати?» |
| Затримка / Зниклі | 2793 / 2695px | 445 | «Офіційні джерела» — сирий стовпчик синіх посилань |

### 1.6. Тексти

Середня довжина речення 11–13 слів — це нормально. Складність читання створюють
не речення, а **довжина рядка (до 150 символів), 13-піксельний кегль і тісний
інтерліньяж**. Тобто це переважно задача типографіки, а не переписування. Але
є що почистити: заголовки секцій на кшталт «Що ви отримуєте на практиці»
не обіцяють нічого конкретного.

## Частина 2. План

### Етап 0. Фото локально
Завантажити всі Unsplash-зображення у `/public/photos`. Прибирає биті банери
й одночасно прискорює завантаження (зараз 12 зовнішніх запитів до CDN).

### Етап 1. Типографіка — Literata + IBM Plex Sans

Нова шкала:

| Роль | Було | Стане |
|---|---|---|
| h1 | 34 / 44 | **44 / 52** |
| h2 | 26 / 36 | **32 / 42** |
| h3 | — | **22 / 30** |
| Основний | 16 / 24 | **17 / 28** (1,65) |
| Допоміжний | 13 / 20 | **15 / 24** |
| Довжина рядка | до 1120px | **68ch (≈640px)** |

Literata має вісь optical size: у 44px вона стає контрастнішою й гострішою,
у дрібному кеглі — міцнішою. Це те, чого не вміє Source Serif, і саме це
дає відчуття зробленого вручну. IBM Plex Sans має характерні термінали
й не схожий на Inter/Roboto/Source. Обидва — повна кирилиця, змінні шрифти.

### Етап 2. Ритм і повітря

Три рівні розділення замість поточних 32px і 0px:

```
96px  між великими смисловими розділами
64px  між підрозділами всередині розділу
40px  між блоками одного підрозділу
```

Плюс: FAQ 4px → 12px; фільтри 16px → 24px; довжина рядка 68ch;
на «Корисній інформації» два CTA поспіль зводяться до одного.

### Етап 3. Навігація

```
Що сталося ▾    Наша допомога ▾    Інструкції    Про нас    Контакти
```

Кожен пункт випадайки з підписом-поясненням:

```
[Що сталося ▾]
  Загинув військовослужбовець
     Які виплати належать родині й у якому порядку
  Виплату затримують або відмовили
     Як зафіксувати бездіяльність і оскаржити
  Зниклий безвісти або в полоні
     Права родини, поки статус не встановлено
  Пенсія, компенсації, статуси
     Що ще може належати родині
```

Мобільне меню отримує ту саму групу. Футер перегруповується: «Ситуації» /
«Про практику» / «Документи сайту» — без змішування намірів.

### Етап 4. Контекстні переходи

Однаковий фінальний блок на 13 сторінках замінюється на «Далі за темою»:
2–3 посилання, релевантні саме цій сторінці, плюс один CTA. Приклад для
сторінки «Затримка»:

```
Далі за темою
→ Зразок скарги на бездіяльність          (Інструкції)
→ Які виплати взагалі мали б надійти      (Виплати у разі загибелі)
→ Скільки коштує оскарження               (Послуги)
```

Це одночасно навігація, засіб від глухих кутів і найдешевший спосіб
прибрати відчуття шаблону.

### Етап 5. Другорядні сторінки лаконічніше

- **Контакти**: hero стискається, три картки перебудовуються, зайвий CTA прибирається
- **Затримка / Зниклі**: два блоки «покроково» розділяються візуально; «Офіційні джерела» стають структурованим блоком із поясненням, що де шукати
- **FAQ**: групування за темами, повітря між позиціями
- **Корисна інформація**: один CTA замість двох

### Етап 6. Власна графічна мова

- асиметрична сітка на контентних сторінках (текст 68ch зліва, примітки й дати на полях справа) замість центрованої колонки на всіх сторінках однаково
- типографічні акценти — виносні цитати, нумерація на полях — замість «загорнути все в картку»
- різний ритм відкриття сторінок: не кожна починається фото-полотном
- фірмова деталь у заголовках розділів замість універсальної рисочки

### Етап 7. Команда — 5 карток за напрямами

```
Виплати у разі загибелі
Оскарження і представництво в суді
Зниклі безвісти та військовополонені
Пенсії, компенсації, статуси
Документи і контроль строків
```

Кожна картка має поля під ім'я, фото, стаж і номер свідоцтва в `src/config/site.ts`.
Структура готова — залишається підставити реальних людей.

### Етап 8. Редактура текстів
Заголовки секцій переписуються так, щоб обіцяли конкретику. Канцелярит забирається.
Заборони ТЗ лишаються чинними: жодних гарантій виплат, жодної непідтвердженої статистики.

### Етап 9. Верифікація
Ті самі заміри повторно на 1280 / 768 / 390px: висота сторінок, розриви, довжина рядка,
кеглі, горизонтальний скрол, контраст WCAG AA. Плюс `next build`.

## Частина 3. Результат (заміри після)

| Що | Було | Стало |
|---|---|---|
| Мін. розрив між розділами | 20px (Послуги), 32px (Затримка, Виплати) | **52px**; медіана 80–96px |
| Довжина рядка | до 1120px ≈ 150 символів | **64ch ≈ 750px ≈ 70–74 символи** |
| h1 / h2 | 34 / 26px | **44 / 32px** |
| Основний текст | 16px, інтерліньяж 1,5 | **17px, 1,65** |
| Найдрібніший текст | 13px (39 елементів на сторінці) | **14px, нижче не опускається ніде** |
| Однаковий фінальний блок | 13 сторінок із 13 | **0** — у кожної свій набір переходів |
| Однаковий фото-вступ | 12 сторінок із 13 | **7** — решта має типографічний або стислий вступ |
| Картки команди | 2 | **5 за напрямами роботи** |
| Горизонтальний скрол | — | немає на 1280 / 768 / 390px |
| JS-помилок | — | 0 на всіх 13 сторінках × 3 ширини |

### Що зроблено понад план

- **Виток IP-адрес відвідувачів.** Фото хотлінкалися з `images.unsplash.com`
  звичайним `<img>`, тобто браузер кожного відвідувача звертався до
  стороннього CDN. Переведено на `next/image` з проксіюванням — зображення
  тягне наш сервер. Побічно: AVIF/WebP і правильний розмір під екран
  (на телефон 390px їхав JPEG шириною 1600px).
- **Подвійний заголовок** «Вартість і формати допомоги» + «Вартість послуг»
  за 20px один від одного.
- **Мобільне меню**: заголовок обрізався зверху, назви пунктів ховалися
  в три крапки.
- **Перенос шапки на два рядки** на 1024px після збільшення кегля.

## Що потрібно від власника

1. **Фото спеціалістів** — у цій сесії вкладення не надійшли. Портрет 800×1000,
   ділове вбрання, нейтральне тло.
2. **Імена, посади, номери свідоцтв** для 5 карток.
3. Підтвердження цифр у блоці «Практика в цифрах» (12 адвокатів / 200+ справ / 20 років).
